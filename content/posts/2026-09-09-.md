## 各类保险的含义


| 优先级 | 保险 | 解决什么 | 普通年轻人 |
| --- | ---------- | ------------- | ----------- |
| ① | **基本医保** | 看病的基础报销 | 🔴 必须有 |
| ② | **百万医疗险** | 几万～几十万甚至更高医疗费 | 🔴 强烈建议 |
| ③ | **意外险** | 意外身故、伤残、医疗 | 🔴 强烈建议 |
| ④ | **重疾险** | 生大病后收入中断 | 🟡 建议 |
| ⑤ | **定期寿险** | 自己去世后家人的生活 | 🟡 有家庭责任后必配 |
| 后面 | 年金/增额寿/储蓄险 | 长期储蓄、现金流 | ⚪ 最后考虑 |


## 普通年轻人的“基础版保险组合”

25～35岁、身体健康、正常工作、有医保、无孩子


| 保险 | 建议 |
| ----- | ------------------ |
| 基本医保 | 保持连续 |
| 百万医疗险 | 200万+医疗额度，优先长期保证续保 |
| 意外险 | 50～100万身故/伤残 |
| 意外医疗 | 2～5万+ |
| 重疾险 | 30～50万 |
| 定期寿险 | 无家庭责任暂缓 |


## 保险检查条款清单


| 项目 | 必看 |
| ------ | ---------- |
| 保险责任 | 到底什么情况赔 |
| 责任免除 | 什么情况不赔 |
| 等待期 | 生效多久以后才赔 |
| 健康告知 | 哪些健康问题必须申报 |
| 医院范围 | 哪些医院能赔 |
| 免赔额 | 自己先承担多少 |
| 赔付比例 | 100%还是其他 |
| 医保外费用 | 能不能报 |
| 院外药 | 是否赔 |
| 续保 | 是否**保证续保** |
| 保证续保期限 | 保多久 |
| 费率调整 | 能否涨价、怎么涨 |
| 职业限制 | 自己职业是否符合 |
| 犹豫期 | 反悔规则 |
| 现金价值 | 长期险退保能拿多少 |
