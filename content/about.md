你好，我是 Naiveda。

这里是我的个人数字花园，用来记录学习、思考与实践。

## 我在这里记录什么

主要包括：

- 技术与工程实践
- 学习方法与知识整理
- 阅读与思考
- 工具与效率
- 一些值得长期保存的发现和想法

## 文章与笔记

这个网站主要有两类内容：

**文章**
相对完整、经过整理的内容。

**笔记**
一些更轻量的想法、发现、阅读记录与实践片段。

我更希望这里是一个持续生长的知识空间，而不只是一个只发布“完成品”的博客。

## 关于这个网站

本站基于 Hugo + PaperMod 构建。

内容通过 Pages CMS 管理，源码托管于 GitHub，并通过 GitHub Actions 自动部署到 GitHub Pages。
